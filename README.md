# 🎬 Prime Video Interactive Dashboard & Data Analysis

An interactive Business Intelligence (BI) dashboard built using **Power BI** to analyze Prime Video's content catalog, including movies, TV shows, release trends, geographic distribution, and content ratings.

## 📈 Key Performance Indicators (KPIs)

The dataset provides a comprehensive overview of the Prime Video library with the following core metrics:
* **Total Titles:** 9,655
* **Total Ratings:** 25 categories/levels
* **Total Directors:** 5,771 unique directors
* **Timeline Span:** From **1920** to **2021**

---

## 🔍 Key Visualizations & Insights

1. **Content Type Distribution:** 
   * **Movies:** 7.81K (80.82%)
   * **TV Shows:** 1.85K (19.18%)
2. **Geographic Distribution (`Total Shows by Country`):** Interactive map visualizing content production and availability across different countries worldwide.
3. **Content Growth Over Time (`Total Shows by Release Years`):** A line chart tracking the exponential growth of movie and TV show releases leading up to 2021.
4. **Ratings Breakdown (`Rating by Total Shows`):** Bar charts detailing the distribution of content based on age ratings and suitability (e.g., 13+, 16+, 18+, ALL, R, PG-13).
